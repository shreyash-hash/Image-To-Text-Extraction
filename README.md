# Image to Text Extraction

Image to Text Extraction is a OCR (Optical Character Recognition) model which extracts texts from images. It uses Tesseract to do so.


###  What is OCR ?
OCR (Optical Character Recognition) is a technology that converts different types of documents — such as scanned paper documents, PDF files, or images taken by a digital camera — into editable and searchable data.

In simple terms, OCR extracts text from images or scanned documents and turns it into machine-readable text.


### What is Tesseract ?
Tesseract is an open-source Optical Character Recognition (OCR) engine developed initially by HP and now maintained by Google. It is widely used to extract text from images, scanned documents, or even handwritten content. It is used with the integration of pytesseract which is python wrapper for Tesseract OCR.






## Features


| Feature                 | Description                                                                                   |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| 🔤 Text Extraction      | Converts printed or handwritten text in images to machine-readable text.                      |
| 🌐 Multilingual Support | Supports **100+ languages**, including custom-trained languages.                              |
| 🧠 LSTM Engine          | Uses **Long Short-Term Memory (LSTM)** neural networks for better accuracy (since version 4). |
| 📄 PDF Output           | Can output searchable **PDFs** with recognized text.                                          |
| 🔧 Command Line Tool    | Can be used via terminal or integrated with programming languages like **Python**.            |
